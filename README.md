# EnglishPod 365 · 在线精听工作台

一个**零依赖的单页工具**，把 EnglishPod 全 365 期的对话音频整理成可以按难度筛选、倍速播放、边听边记笔记的练习台。**不用下载任何音频**，浏览器打开就能练。

> A single-file web app for practicing English listening with all 365 EnglishPod episodes — no audio download needed, play straight from the browser.

---

## 直接开始

**在线使用（推荐）**：<https://jiks999.github.io/englishpod-365/>

打开就有一份 365 期的列表，点任意一期即可播放。学习进度和笔记保存在你自己的浏览器里，不会上传到任何服务器。

**本地使用**：下载仓库 zip，解压后双击 `index.html`。

## 它能做什么

| 功能 | 说明 |
|---|---|
| 365 期全量目录 | 期号、标题、难度、栏目都在，按 C/B/D/E/F 分级筛选 |
| 在线播放 | 音频来自 archive.org 公开存档，`preload=none`，点播放才加载 |
| 倍速 | 0.7× / 0.8× / 0.9× / 1× / 1.2×，选择会被记住 |
| 循环 + 上下期 | 适合单句反复磨；↑↓ 键切换上一期下一期 |
| 学习状态 | 未开始 / 精听中 / 已完成 + 星标，随时筛出没练过的 |
| 笔记 | 每期一个笔记框，自动保存，Ctrl+S 手动保存 |
| 导出 | 一键导出 Markdown 笔记（按你的排版存成 .md）；也能备份/恢复 JSON |
| 搜索 | 搜期号、标题、栏目，也能搜笔记内容 |

界面支持深色模式，键盘 ↑↓ 翻页，手机浏览器也能用（窄屏自动上下布局）。

**分享单期**：地址后面加期号就能直达，例如 <https://jiks999.github.io/englishpod-365/#66> 打开第 66 期。发给同学时直接发这个链接。

## 关于难度分级（重要，别被"四级"误导）

网上流传"EnglishPod 分初级/中级/中高级/高级四档"。按官方 PDF 里的级别码实测，365 期的实际分布是：

| 代码 | 级别 | 期数 |
|---|---|---|
| B | Elementary 初级 | 25 |
| C | Intermediate 中级 | 309 |
| D | Upper-Intermediate 中高级 | 4 |
| E | Advanced 高级 | 4 |
| F | Proficient 精通 | 2 |
| — | 无级别码（后期按栏目出） | 21 |

也就是说**绝大多数是 C（中级）**，高难度只有 10 期。从第 10 期起，官方改用栏目分类（Daily Life / The Weekend / The Office / Global View / Advanced Media），难度标签不再出现在标题里。

所以按难度练的正确顺序是：先把 B 的 25 期过一遍，再进入 C 的主体，D/E/F 留到最后。

## 怎么用它练口语（精听 + 跟读）

1. **盲听**：不看任何文本，0.9× 速度把对话听 2-3 遍，只抓关键词，写下你听到的内容
2. **核对**：打开官方 PDF 讲义（见下），对照原文，标出听错、听漏的地方
3. **拆句**：回到音频，一句一句暂停跟读，卡住的地方放慢到 0.7×，练到能跟上
4. **影子跟读**：1× 速度，落后原声半句同步复述，练到不用暂停
5. **复述**：关掉音频，用自己的话把整段对话讲一遍，录音回听
6. **标记**：练完点「已完成」，有难点的加星标，一周后回来重听

一期不要贪快，同一期反复 3-5 天比一天刷十期有用。进度和笔记都在页面里，第二天打开接着练。

## 音频从哪来 / 为什么不带文本

- **音频**：指向 [archive.org 上的 EnglishPod 公开存档](https://archive.org/details/englishpod_all)，本项目**不托管任何音频文件**，只存链接。需要你的网络能访问 archive.org（部分地区需要代理）。
- **PDF 讲义 / 转写文本**：EnglishPod 的课程讲义版权属于 Praxis Language，本仓库不包含、也不再分发。需要对照文本时，请通过官方或你已有的渠道获取；讲义第 1 页就是对话原文和词汇表。
- 这个仓库只包含：界面代码（`index.html`）、课程元数据（`data.js`，期号/标题/难度/在线链接）、构建脚本。

如果你自己有讲义和转写文件，可以克隆本仓库后放到本地目录，再跑一次 `scripts/build_lite.py` 的姊妹脚本补全数据 —— 页面会自动从"仅在线"升级为"本地优先 + 文本对照"。

## 技术说明

- 单文件 HTML + 一份 JSON 数据，无框架、无构建、无后端、无追踪
- 笔记与进度存在浏览器 `localStorage`（键名 `ep_data_v2`）。**按 origin 隔离**：`file://` 打开和 `http://` 打开是两套数据，换方式前先用「备份 .json」导出，再在新地址「恢复」
- 导出笔记是标准 Markdown，可以直接丢进 Obsidian / Notion / 任何笔记软件
- 页面里的 `data.js` 由 `scripts/build_lite.py` 生成，想加期数或改链接改脚本重跑即可

```bash
python scripts/build_lite.py     # 重新生成 data.js（不含文本，音频走在线源）
```

## 常见问题

**Q：点播放没反应 / 一直转圈？**
A：音频在 archive.org，需要能访问它。国内网络通常要开代理。页面会提示"在线音频加载失败"。

**Q：能离线用吗？**
A：界面可以，音频不行。想离线就把音频下到本地，用自己的播放器配合讲义练。

**Q：我的笔记会丢吗？**
A：存在浏览器本地。清缓存、换浏览器、换电脑都会丢，重要笔记记得定期「导出笔记 .md」。

**Q：能加别的播客吗？**
A：可以。`data.js` 结构很简单（`id / code / topic / title / online`），照着加就行；有本地文件时再补 `audio / pdf / srt / text` 字段。
